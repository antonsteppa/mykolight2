# mykolight2

Статичний сайт для перегляду графіка відключень електроенергії в Миколаєві.

Проєкт навмисно простий:
- один HTML-файл із вбудованими CSS і JavaScript
- без збірки
- дані завантажуються з Google Sheets під час відкриття сторінки

## Що вміє сайт

- Показує погодинний графік для черг `1.1` - `6.2`
- Підсвічує поточний півгодинний слот
- Підтримує пошук за адресою через підготовлену адресну таблицю
- Працює і на десктопі, і на мобільних пристроях

## Джерела даних

Поточні джерела:
- графік береться з вкладки `Data`
- адреси беруться з вкладки `AddressData`

Ідентифікатори таблиць і назви вкладок задані прямо в [index.html](C:\Users\Ton\Documents\Codex\2026-04-19-github-plugin-github-openai-curated-inspect\index.html:268).

Фронтенд читає обидві таблиці через Google Visualization JSONP, тому сайт може залишатися повністю статичним і водночас підвантажувати дані в браузері.

## Формат адресної таблиці

Пошук за адресою залежить від попередньо згенерованої вкладки `AddressData`.

Очікувані колонки:

1. `idfilial`
2. `filial`
3. `idnaspunkt`
4. `naspunkt`
5. `idstreet`
6. `street`
7. `iddom`
8. `dom`
9. `queue_name` (необов'язково)
10. `outage_type` (необов'язково)

Якщо `queue_name` порожнє, ланцюжок вибору адреси все одно працює, але фінальний пошук не зможе прив'язати будинок до черги.
